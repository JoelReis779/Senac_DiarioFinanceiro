# 💰 Diário Financeiro (Senac)

O **Diário Financeiro** é um sistema web desenvolvido para melhorar a conscientização dos usuários sobre suas finanças e proporcionar um controle muito maior sobre o orçamento diário, auxiliando na organização prática de receitas e despesas.

---

## 💡 Objetivo

Este projeto nasce da constatação de que o descontrole financeiro é potencializado tanto por fatores econômicos quanto psicológicos, a exemplo da falta de planejamento e do consumo impulsivo.

O sistema busca:
* 🌱 **Educação:** Promover a educação financeira por meio do monitoramento de gastos e de projeções futuras.
* ⚖️ **Simplicidade:** Oferecer uma plataforma simplificada que atenda usuários que buscam simplicidade em detrimento de planilhas complexas.
* 🧠 **Decisão:** Auxiliar na tomada de decisão através de relatórios claros e integridade das informações.

## 🚀 Como Executar o Projeto Localmente

### 🔧 Pré-requisitos

Antes de iniciar, é necessário ter instalado:
* [XAMPP](https://www.apachefriends.org/)
* Navegador Web (Google Chrome, Firefox, Edge, etc.)

### ▶️ Passos para Execução

1.Clone o repositório:
```bash
 git clone https://github.com/seu-usuario/Senac_DiarioFinanceiro.git
 ```
Mova o projeto para a pasta htdocs do XAMPP:

mv Diario.financeiro  /c/xampp/htdocs/

3.Inicie os serviços:
 
 Abra o painel do XAMPP e inicie o servidor **Apache** e o **MySQL**.
 
4.Configure o Banco de Dados:

Crie o banco de dados no *phpMyAdmin* e importe o script SQL fornecido no diretório do projeto.

5.Acesse o sistema no navegador:
```bash
 http://localhost/Diario.Financeiro
```
